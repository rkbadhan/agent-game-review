The line most tools cross

AI interpretation, bounded by evidence.

The reviewer reads the run and explains it in plain language — but it can only claim what the evidence licenses. Relevance is not causality, and the wording is built to say the difference out loud.

Linked to outcome“linked to the failed result”the ceiling
A likely contributor“a probable factor”allowed

Structured facts are recomputed from the immutable source. An interpretation that contradicts the trace is dropped, not softened.

Caused the failure“produced / caused”not licensed
Would have passed“had it done X…”needs a replay

The strong causal claims stay locked until a counterfactual replay can actually support them. The card never overstates its case.

Five-minute path

Clone to a live sweep in a few commands

Builds a synthetic two-configuration sweep and opens the evidence browser — no credentials, no watermarks, no model calls to run the core.

# clone and enter the repo, then install with the HTTP transport
$ git clone https://github.com/rkbadhan/eval-game
$ cd eval-game
$ pip install .[api]

# build the demo sweep and open the browser at :8000
$ agr demo
  ✓ synthetic sweep — 12 runs across 5 tasks
  ✓ evidence browser at http://127.0.0.1:8000

# add AI-enriched review on a real run (optional)
$ agr review run_17 --provider anthropic
